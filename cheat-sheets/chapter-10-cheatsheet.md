# Chapter 10 Cheat Sheet: 60-Minute Exam Strategy

## Pacing Budget (55 questions / 60 min)
| Phase | Time | Purpose |
|---|---|---|
| First pass | ~48-50 min | Answer every question once, ~50-55 sec each |
| Buffer/review | ~10-12 min | Revisit flagged questions only |
| Checkpoint | 30 min mark | Should have ~27-28 answered — if behind, speed up, don't resolve flags yet |

**Rule:** Never leave a question blank. Always submit a best-guess before flagging.

## Flag-and-Skip Workflow
1. Read scenario → extract constraints
2. Form expected answer BEFORE reading options
3. Pick closest match as provisional answer
4. If confidence < high → flag, move on
5. Limit flags to **15-20%** of total questions (8-12 of 55)
6. Revisit flags only after every question has one answer

## Scenario Deconstruction Checklist
- Latency/performance requirement?
- Cost/budget constraint?
- Scale (users, agents, data volume)?
- Data sensitivity/compliance?
- Integration/compatibility requirement?
→ Form your own answer, THEN compare to options.

## Domain-Weighted Review Priority
| Priority | Action |
|---|---|
| 1st | Flagged Qs in highest-weight domains (e.g., Agentic AI Design, Data Processing) |
| 2nd | Flagged Qs in mid-weight domains |
| 3rd | Flagged Qs in lowest-weight domains |

Fix the highest-weight errors first — bigger expected score gain per minute spent.

## Common Distractor Patterns (all 8 domains)
| Pattern | Spot it by |
|---|---|
| Partial-constraint match | Satisfies 2 of 3 requirements — most common trap |
| Deprecated/outdated option | Sounds modern but is legacy |
| Overengineered option | Technically works but violates cost/complexity constraint |
| Right concept, wrong scope | Correct idea applied at wrong layer (agent vs. orchestrator vs. pipeline) |

## Final-Week Checklist
- [ ] Re-attempt all missed practice questions
- [ ] Review "why wrong" explanations, not just "why right"
- [ ] Run one full 60-min timed mock exam
- [ ] Re-skim flashcards on Numbers & Limits
- [ ] Sleep/rest — no new content learning in final 48 hours

## Mindset When Stuck
- No blank answers — guess beats zero every time
- 2 candidates left → eliminate the one breaking a stated constraint
- Don't re-read full scenario under severe time pressure — use constraints already extracted
- Trust first full read; second-guessing rarely improves accuracy under time pressure
