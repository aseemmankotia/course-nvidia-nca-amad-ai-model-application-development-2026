# Chapter 2 Lab: Agentic AI: Tool Use, Planning, and Multi-Agent Orchestration

**Estimated time:** 25 minutes

## Exercise

Sketch an agentic customer-support workflow: define the tools (order lookup API, refund function), the planning loop, a guardrail check, and which steps use a NIM-hosted LLM vs a single direct model call

## Key takeaway

Use an agent only when the task needs tool use, multi-step reasoning, or orchestration — a single model call is the exam's default answer when the task is simple.
