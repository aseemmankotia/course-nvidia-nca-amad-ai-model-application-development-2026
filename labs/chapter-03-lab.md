# Chapter 3 Lab: Data Pipelines, RAG, and the Data Flywheel

**Estimated time:** 25 minutes

## Exercise

Design a RAG ingestion pipeline on paper: raw documents → chunking → embedding model → vector store → retrieval at query time, then add a feedback loop capturing user thumbs-up/down to flag low-quality chunks for the next curation pass

## Key takeaway

The data flywheel turns production usage into a continuous curation and retrieval-quality improvement loop, not a one-time pipeline.
